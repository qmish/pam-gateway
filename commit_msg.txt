Этапы 0.1/0.8/0.10 + 1.1/1.2/1.4: CI coverlet, rate limiting, кэш политик, SIEM, иммутабельность аудита, тесты Agent/UI

- CI: coverlet coverage reports + артефакты отчёта покрытия
- Rate Limiting: ASP.NET Core FixedWindow для auth и api эндпоинтов
- Policy Caching: IMemoryCache для результатов оценки политик (5 мин TTL)
- SIEM Export: фоновый сервис для экспорта аудита через syslog/webhook (CEF формат)
- Audit Immutability: middleware запрещает PUT/PATCH/DELETE на /api/v1/audit
- Agent Tests: unit-тесты регистрации, heartbeat, retry при ошибках
- UI ApiClient Tests: мок HTTP тесты для всех методов клиента
- Тесты: 244 (170 unit + 74 integration), все проходят
