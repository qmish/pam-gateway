# Тестирование и security review

## Функциональные тесты (MVP)
- Вход через Keycloak (SSO) с AD/LDAP.
- Запрос JIT доступа и согласование.
- Подключение по RDP/SSH через брокер.
- Запись и воспроизведение сессий.
- Корректный отзыв доступа по времени.

## Нагрузочные тесты
- 100/500/1000 одновременных сессий.
- Пиковые логины и JIT запросы.
- Проверка устойчивости брокера сессий.

## Security review
- MFA включена для всех пользователей.
- RBAC применяется строго по ролям.
- Запрет прямого доступа к системам.
- Аудит и отправка событий в SIEM.
- Проверка хранения записей сессий.

## Соответствие
- 152‑ФЗ: контроль доступа и журналирование.
- PCI DSS (если применимо): учет привилегированных действий.
- ISO 27001: процедуры управления доступом.

## Выходные артефакты
- Отчет по тестированию.
- Перечень выявленных рисков и план исправлений.
