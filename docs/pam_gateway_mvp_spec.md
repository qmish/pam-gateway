# MVP функции PAM‑шлюза

## Основные функции
- Аутентификация через Keycloak (OIDC/SAML).
- RBAC доступы по ролям и группам.
- JIT доступы с автоматическим отзывом.
- Брокер сессий для RDP/SSH.
- Запись сессий и аудит.

## Сущности доменной модели
- Пользователь (User)
- Роль (Role)
- Политика (Policy)
- Система (Target)
- Сессия (Session)
- Заявка/разрешение (Approval)

## Минимальные сценарии
1) Пользователь запрашивает доступ к системе (JIT).
2) Согласование (минимальный approval).
3) Доступ через брокер сессий.
4) Запись действий и логирование в SIEM.

## Политики доступа
- JIT по времени (2–8 часов).
- JEA для критичных операций.
- Прямой доступ к системам запрещен.

## Форматы логов
- Логин, выдача доступа, окончание сессии.
- Эскалации и неуспешные попытки.

## Выходные артефакты
- Спецификация API (минимум: auth, access, session).
- Модель ролей и политик.
- Шаблоны конфигурации брокера сессий.
