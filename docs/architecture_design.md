# Архитектурный дизайн PAM и шлюза

## Логическая архитектура
Компоненты:
- VPN‑шлюз (доступ в периметр)
- ZTNA/Policy Engine (контекстные политики)
- PAM Vault (секреты и ротация)
- PAM Session Broker (подключения)
- Session Recording (запись и хранение)
- Интеграции: AD/LDAP, SIEM, ITSM, CMDB, PKI

## Сегментация сети (пример)
- DMZ: VPN/шлюз доступа
- Security Zone: ZTNA/Policy Engine, PAM Access
- Core: PAM Vault, Recording Storage
- Managed Zone: корпоративные системы

## Высокая доступность и DR
- Актив‑актив кластер для Session Broker
- Актив‑пассив для Vault с синхронизацией
- Репликация записей сессий на защищенное хранилище
- Регулярное резервное копирование секретов и конфигурации

## Интеграции
- AD/LDAP: аутентификация и группы
- SIEM: поток логов и корреляция
- ITSM: заявки на доступ, approvals
- CMDB: актуальный каталог систем
- PKI: сертификаты и mTLS

## Политики доступа
- RBAC по ролям и типам систем
- JIT доступы с ограниченным временем
- JEA (минимальные привилегии)
- Break‑glass с обязательной записью сессии

## Выходные артефакты этапа
- HLD (High Level Design)
- SLD (детализированная схема сети)
- Модель ролей и политик доступа
