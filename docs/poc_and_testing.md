# PoC и нагрузочные тесты

## Цели PoC
- Проверить критичные сценарии администрирования
- Оценить удобство и безопасность работы через PAM
- Валидировать производительность и отказоустойчивость

## Сценарии PoC
- Windows администрирование через RDP
- Linux администрирование через SSH
- Администрирование сетевого оборудования (CLI)
- Работа с БД (SQL клиент)
- JIT доступ на ограниченное время
- Ротация паролей и проверка audit trail

## Метрики и критерии приемки
- Время выдачи доступа (SLA)
- Наличие записи сессий
- Отказоустойчивость при падении 1 ноды
- Успешная ротация 95%+ учетных записей

## Нагрузочные тесты
- Одновременные сессии (N100/N500/N1000)
- Пиковые подключения VPN
- Объем записи сессий в час
